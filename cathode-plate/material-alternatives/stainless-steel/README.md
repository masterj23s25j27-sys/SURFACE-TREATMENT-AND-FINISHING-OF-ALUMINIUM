# Stainless steel cathodes

Stainless steel is reported as an option in some anodizing applications, but compatibility depends on bath chemistry, temperature, contamination sensitivity, and the process specification. It is not the default recommendation in the supplied AAC sulfuric-acid aluminum-cathode bulletin.

Before use, document the grade, corrosion behavior, possible contamination, electrical contact design, and results of a controlled process trial. A generic statement that a stainless grade is corrosion resistant is not sufficient approval for a specific anodizing bath.
